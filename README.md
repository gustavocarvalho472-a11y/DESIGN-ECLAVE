# Eclave · Site do Sérum Clareador Noturno

Funil de venda em HTML/CSS/JS puros, sem build, publicado no GitHub Pages.

- `index.html`: landing page
- `upsell.html`: oferta de 1 clique
- `obrigado.html`: confirmação da compra
- `design-system/`: tokens de cor/tipografia e logos oficiais
- `HANDOFF.md`: especificação do design e pendências antes de divulgar

Para ver localmente: `python -m http.server 8080` e abrir http://localhost:8080
